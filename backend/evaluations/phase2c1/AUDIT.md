# Pre-training audit and frozen comparison design

Base `ed267de`. Protocol `protocol.json` is specified before any pilot training or held-out evaluation. All reward weights remain unchanged. The pilot is explicitly bounded and may fail to converge; poor test performance will not trigger additional training.

Phase 2B audit:

- State: exactly 14 retained original features (indices 0–9 and 11–14), six risk features, six validity bits, two normalized class exposures and two exposure-known bits. HOL h/(1+h) preserves the deadline threshold at 0.5. Unknown rates have invalid bits, never valid zero. Class exposures require a full 100-ms window and at least 20 matured arrivals per connected UE. Previous reserve deltas and current mode are represented separately. The original 15-feature encoder is unchanged.
- Actions: index `2*(7*e+u)+mode`, 98 nominal actions. The mask and atomic bridge share quota and mode/budget checks; return rules are baseline floors. At zero occupancy negative returns are invalid; at full occupancy net-positive increments are invalid. Limited valid sets are sampled/greedily maximized only within the mask.
- Reward: the read-only event ledger counts the union of overflow, expiry and late completion once. Matured worst-UE failure risk is an absolute risk, not a disparity bonus. It is repeated risk-duration shaping, distinct from the exactly-once event term. The terminal administrative charge is separate from observed misses. Already failed pending traffic is not charged twice. Switching costs 0.01 once on the first subsequent service tick. The five costs retain weights 1, .25, .10, .02, .01 and the 80-batch reference denominator. No future events or final reports are inputs.
- Learning: bounded replay copies state/action/reward/next-state/mask/done; masked terminal TD targets have no bootstrap. Target synchronization is by optimizer-update count. Joint loss is Huber with norm clipping 10; the original source DQN uses MSE without clipping. The pilot preserves those loss differences while matching interaction budgets, hidden-layer sizes and optimizer hyperparameters. No correctness fault in Phase 2B attribution was found.

Risks to diagnose rather than silently fix: terminal charges depend on horizon; a saturated worst-UE risk can hide improvements for other UEs; warmup makes fairness shaping temporarily unavailable; a 100-ms historical rate crosses multiple policies; aggregate state is partially observed; legacy reward uses average latency and a different eMBB target from joint reward. Legacy returns and joint returns have different units/scales and are not compared as performance scores. Learning curves must be separated from independent batch/byte/HOL outcomes. The fixed radio/traffic seeds and one network seed cannot establish generalization or a convergence distribution.

Necessary pipeline additions: independent network and scenario seeds; fresh single-episode simulator reset for each scenario so placement does not depend on catalog index or method ordering; deterministic exploration schedule; common held-out censoring/metrics; a conservative resource watchdog below 3 GiB. Phase 2B defaults/checkpoint schemas remain compatible. No physical/radio/jammer/scheduler/traffic change is planned.

Baselines: B0 zero activated reserve/P; B1 reference validator's aggressive reactive reserve heuristic/P; B2 same heuristic/F; B3 original 15-state/49-action network and original reward/P; B4 same/F; B5 same reserve learning objective with a causal hysteretic mode rule, trained separately after freezing the rule; P original Phase 2B 30-state/98-action joint DQN. B1/B2 reuse reference reserve-target and nearest-valid-action functions; they observe current baseline loss, not future jamming. All methods start with zero activated reserve and share identical placement/channel/arrival/deadline/jammer fingerprints within every pair.

B5 enters F if valid current maximum HOL/budget exceeds the entry threshold; exits to P only after two consecutive decision observations at or below half that threshold. Missing pressure holds the current mode. Initial mode is P. Candidates .75 and 1.25 are evaluated on validation only using B3's selected reserve weights, then the chosen rule is frozen before B5 is trained from scratch. This limited transfer probe is not called an independently optimized candidate; the final B5 is retrained under its own switching environment.

Training is nine independent 3-second episodes per learned method (3 scenario seeds × 3 severities), 2691 observed transitions, one gradient step per new transition after replay contains 32. Replay 2048, Adam 1e-4, gamma .99, target every 100 updates. Epsilon decreases linearly from 1 to .05 over 80% of that fixed interaction budget, then stays .05. All methods use the same scenario order and network seed, with separate random streams for simulator and learning. This is nine times the Phase 2B transition budget, selected from its measured ~4.2-second episode runtime, not a convergence assertion.

Save candidates after 3/6/9 episodes; greedily evaluate each on j0/j10/j20 with validation seed 2101. Minimize the common physical tuple in the protocol, not cross-objective returns. Held-out seeds 3101/3102 are used only after checkpoint/rule selection is frozen. Report offered failure lower/upper bounds with unresolved-not-due traffic separated for every method; terminal administrative charges are never added to physical known-miss counts. All-UE recovery requires 10 ms of simultaneous queue-budget compliance after each jammer-OFF transition; no OFF event is N/A, failed recovery is right-censored. Full cohort accounting covers initialization service as well as learned intervals.

Original Phase 1.2 operating regimes require generated, capacity-scaled CSVs. They are excluded because this phase prohibits changing traffic traces. Report attainable fluid load as a diagnostic only; do not label it a proof of deadline feasibility. No reward retuning, new training seed, extended horizon, budget escalation or full journal sweep will be triggered by held-out results.
